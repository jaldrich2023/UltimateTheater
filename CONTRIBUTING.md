# Contributing to Ultimate Theater

Thanks for your interest in Ultimate Theater.

Ultimate Theater is **proprietary software** (see [LICENSE](LICENSE)). The source code is public so people can read it, but it isn't open source.

## What's welcome

- **Bug reports.** Open an issue with the **Bug report** template.
- **Feature requests.** Open an issue with the **Feature request** template.
- **Questions about how something works.** Check the [User Manual](docs/USER_MANUAL.md) and [Known issues](docs/KNOWN_ISSUES.md) first.

**Code contributions are accepted only by prior arrangement.** Please don't open pull requests that haven't been agreed beforehand, because they can't be merged. If you'd like to help with code, open an issue describing what you'd like to do, and wait for a reply first.

**Security vulnerabilities** must not be reported in public issues. Follow [SECURITY.md](SECURITY.md) instead.

## How to write a good bug report

Before you report:

- Search the [existing issues](https://github.com/jaldrich2023/UltimateTheater/issues) and [Known issues](docs/KNOWN_ISSUES.md). Your problem may already be known.

Include:

- **The Ultimate Theater version** (**Ultimate Theater › About Ultimate Theater**, for example "Version 1.0 (1)").
- **The macOS version** (Apple menu › About This Mac) and your Mac model (Apple silicon or Intel).
- **Steps to reproduce:** what you did, what you expected, and what happened instead.
- **For playback problems, the file's format.** Include the container (MKV, MP4, AVI, TS…) and the video, audio and subtitle codecs. The title page's **About** section lists the file's format and its audio and subtitle tracks. A tool such as MediaInfo can show the rest. Also say whether the file is on the Mac, on an external drive, or on a network share.
- **For casting problems,** the device's make and model (for example "Chromecast with Google TV" or "LG webOS TV"), and what the Cast menu said about the file.
- **For problems finding the right movie or show,** the exact file name and the names of the folders it's in.
- **Screenshots or a screen recording,** if they help.

## Keep personal data out of issues

Issues are public. Please **don't** include:

- API keys (TMDB, OMDb, OpenSubtitles), your OpenSubtitles login, PINs, or pairing codes,
- email addresses, real names of household members, or profile pictures,
- full file paths that reveal personal information (shorten them, for example `…/Movies/Heat (1995).mkv`),
- IP addresses, network names, or QR codes from **Settings › Remote**,
- copyrighted media files. Describe the file instead, or attach a short sample you made yourself.

## Feature requests

Describe the problem you want solved, not only the solution. Say how you'd use the feature, and whether another app does something similar.
